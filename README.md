# E-Library & Book Buying Application 📚

A full-stack MERN application that allows users to browse, search, manage, review, rate, and purchase books through an interactive and responsive web interface.

## Features

- User Registration
- User Login
- JWT Authentication
- Logout Functionality
- Add Books
- View Books
- Search Books
- Update Books
- Delete Books
- Ownership-Based Authorization (Only the book owner can edit or delete their books)
- Cloudinary Image Upload for Book Covers
- Responsive Book Catalog
- Dedicated Book Details Page
- Favorites Management
- Shopping Cart Functionality
- Dynamic Routing for Individual Books
- Book Rating System
- Average Rating Calculation
- Book Reviews System
- Review Submission and Display
- Suggested Books Based on Category
- More Books Discovery Section
- Mobile Responsive Design

## Key Functionalities

### Authentication

- Secure user registration and login
- JWT-based authentication
- Protected routes
- User session persistence

### Book Management

- Add new books
- Upload book cover images
- Edit book details
- Delete books
- View complete book information
- Search books by title

### Ownership Authorization

- Only the user who created a book can edit it
- Only the user who created a book can delete it

### Shopping Cart

- Add books to cart
- Remove books from cart
- Manage cart items
- View selected books before purchase

### Book Details Page

- Large book cover display
- Author information
- Publisher information
- Category and sub-category details
- Language and page count
- Publication year
- Price and MRP display
- Description section

### Ratings & Reviews

- Star-based rating system
- Update existing ratings
- Average rating calculation
- Submit reviews with ratings
- Display reviews in responsive review cards

### Recommendations

- Suggested books based on the same category
- Additional "More Books" section for further exploration

### Responsive Design

- Mobile-friendly layouts
- Responsive navigation
- Optimized book cards
- Responsive review and recommendation grids
